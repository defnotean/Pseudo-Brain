# Phase 2.6 Dynamic-K v1: isolation + instrumentation result (2026-08-22)

**Design:** three arms, identical recipe/seed/steps (6k multitask):
`fixed` (no gate), `soft_modulate` (gate, zero cost pressure), `dynamic`
(gate + annealed temperature 2.0→0.5 + compute-cost ramp 0→0.03). Gate
instrumentation: soft-K per task; escalation phase-binned eff-K at eval.
Data: Spark `runs/dynamic_k_v1_results.json`.

## Headline [MEASURED]

| Arm | Mean lift | Tasks above | Latency (ms) | Phase eff-K (S0→S3) |
|---|---|---|---|---|
| fixed | −0.2059 | 1/25 | 1.34 | — |
| soft_modulate | −0.2059 | 1/25 | 1.95 | **20.9 → 14.2** (S1=S2=S3) |
| dynamic | −0.3567 | 1/25 | 1.95 | 32.0 flat (never closed) |

## Findings

1. **The v0 improvement did NOT replicate.** With the v0 wrapper's exact
   comparison repeated under the v1 harness, soft modulation = fixed exactly
   (−0.2059 both, 1/25 both). The v0 gain (+0.071, 14/25 head-to-head) is not
   reproducible under the restructured forward path — the v1 GatedPB reimplements
   the forward loop (single gate application per cycle vs v0's different wiring),
   so the honest conclusion is: [MEASURED] v0's positive signal was
   implementation-sensitive and did not survive re-implementation. This is a
   valuable negative — it kills the "learned residual scale" story before it
   could mislead the BrainCell workstream.

2. **Compute cost pressure made things worse, not selective.** The `dynamic`
   arm (cost ramp) degraded lift to −0.3567 and its gates pinned fully open
   (eff-K 32 flat) — the cost gradient was absorbed without inducing closure.

3. **Soft modulation produced the most interesting artifact:** phase-binned
   eff-K 20.9 in S0 (8 worlds) dropping to 14.2 after the first cue and staying
   there. Direction is right (more capacity when uncertainty is high) but the
   resolution is coarse: no further reduction at S2 (2 worlds) or S3 (resolved).
   [HYPOTHESIS] this may reflect input-novelty-driven gate activity rather
   than hypothesis-count tracking — the S1/S2/S3 cues are visually similar, so
   the gate cannot distinguish them. It did NOT come with a performance gain
   (lift identical to fixed), so it is not evidence of adaptive cognition yet.

4. **Latency cost of the gate is real:** 1.34 → 1.95 ms (+45%) for zero
   measured benefit in this harness. Any future gate mechanism must clear this bar.

## Verdict per the owner's decision rule

> "If true Dynamic-K does not outperform simple soft modulation, keep the
> modulation mechanism and reject the lifecycle claim."

[MEASURED] True Dynamic-K (cost-driven closure) performed strictly worse than
soft modulation and never closed. **Lifecycle claim: REJECTED at v1.**
Soft modulation's v0 advantage failed to replicate under re-implementation,
so it does not carry forward as an accepted mechanism either — recorded as
implementation-sensitive, unreplicated.

## What carries forward

- Gate telemetry harness (per-task eff-K, phase binning) — reusable for any
  future lifecycle attempt and for BrainCell candidate evaluation.
- The escalation phase-binning result suggests gates respond to input novelty,
  not hypothesis count — a concrete target if lifecycle is revisited post-Core-V1.
- Both v0/v1 scripts + data preserved in-tree; no mechanism enters Core V1
  from this workstream.
