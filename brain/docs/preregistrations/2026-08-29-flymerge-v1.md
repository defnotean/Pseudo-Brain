# FlyMerge V1 — insect-nervous-system computational principles merged onto the reactive baseline (preregistration)

**Frozen:** 2026-08-29, before any Model C training or scenario evaluation.
**Branch:** `biogenesis/flymerge-v1`. Experiment dir: `brain/experiments/flymerge_v1/`.
**Scope:** TRAIN partition only (diagnostic + development discipline; no
DEV/CAL/TEST seed touched; no qualification claim — this is an L-series-style
controlled experiment whose conclusions are architectural, not publishable
scores).

## 0. Core question

Does a specific computational principle observed in insect nervous systems —
a **fast innate channel shunting persistent action-selection state** —
measurably improve Pseudo-Brain's closed-loop decision-making (goal
persistence, recovery, state-dependent behavior) **without** destroying the
reactive baseline's ghost-avoidance capability, under matched parameter,
training, and latency budgets?

## 1. Biological mechanisms investigated (summary; full table in run report)

| # | Mechanism | Bio evidence | Computational principle | Selected? |
|---|---|---|---|---|
| 1 | Fast innate threat channel (LC4→giant-fiber; T4/T5→lobula plate; commandered, stereotyped, ~few synapses) | Neuron 2017 S0896-6273(17)30474-9; PMC10264346 | Small dedicated stimulus→action pathway that **gates (shunts) ongoing selection** while active | **YES (C-core)** |
| 2 | Persistent action-selection / goal state (central complex EB/PB ring attractor; FKF/FG feedback loops; connectome eLife 66039; Kim et al. 2017) | ring attractor holds a bump without sensory input; PFL3→ME visuomotor transform | Low-dim **persistent internal state** that survives sensory dropout and biases action selection | **YES (C-core)** |
| 3 | Neuromodulation (octopamine/dopamine; slow, gain-like, non-commandeering) | root et al. reviews; CX modulatory structure | Global slow variables **modulate gains**, don't command actions | **YES, as one scalar** (risk gain), ablated separately |
| 4 | Appropriate-cost foraging / marginal value (central-complex + modulatory) | Siju & Barbara 2020 eLife | Patch-depletion → explore/switch pressure | DEFER (needs reward signal design beyond BC budget; not the observed failure) |
| 5 | Optomotor / feedback stabilization | T4/T5 + electrical-synapse tracking | Negative-feedback motor correction | DEFER (harness has no slip dynamics) |
| 6 | Habituation / motor programs (descending neurons, sequences) | DNeB connectome | Temporal program expansion | DEFER (no sequential motor structure in 5-class task) |

**Minimum viable combination selected: (1) + (2) + one modulatory scalar (3).**
This maps exactly onto the observed T1-4 failure: near-inert lockup on F0/F4
is a *selection-state* failure (nothing holds "keep foraging" when the
teacher's manifold is left), and the never-dying property is the *fast
channel* working. We test whether adding persistent selection state to the
fast reactive channel converts inertia into recovery without hurting
avoidance.

## 2. Models (all pixel-only, constitution C8: rendered frames +
previous applied action; no coordinates, reward, clock, or privileged state
ever enters ANY model input)

- **A — ReactiveBaselineV1 (frozen, untouched):** the T1-4 checkpoint
  (133,773 params), last-4 frames + prev action → 5-class argmax.
- **B — ReactiveBaselineV1-recurrent (matched control):** same conv trunk,
  same param budget ±2%, trunk output compressed to a GRU cell state h∈R^32
  updated every tick, action head reads (features ⊕ h). Isolates "recurrent
  memory alone" from "fly-structured memory".
- **C — FlyMergeV1 (bio-merge):** Model B's trunk+GRU **plus**:
  - **Innate channel** I: a tiny learned map from the current frame to a
    scalar threat urgency u∈[0,1] (no recurrent state; 1 conv 1x1 over trunk
    features — shallow-pathway abstraction).
  - **Shunting inhibition:** persistent-state update is gated:
    `h' = (1−g(u))·GRU(h, f) + g(u)·h` with `g(u)=sigmoid(a·u+b)` learned;
    high urgency freezes goal state (biological analogue: escape depolarizes
    selection circuits, freezing ongoing goal maintenance). The innate
    channel's action contribution enters the logits additively
    (bypass logit) so it can act even when the policy is off-manifold.
  - **Modulatory scalar:** urgency additionally scales the policy head's
    logit temperature (gain modulation), learned, never commands actions
    directly.
  - Param budget: within 2% of A (133,773 ± 2,675). The trunk is the shared
    trainable core; the persistent state is h∈R^32.

**Training (A-comparable, frozen):** same T1-3 corpus (sha
`59c41b6dc71f…`), same supervision (teacher's applied action, 5-class CE),
AdamW lr 5e-4 wd 1e-4 clip 1.0 batch 16, 6000 steps, seeds 42/142/242/342.
Model C gets **no auxiliary loss, no privileged target** — the innate channel
learns only from the same BC labels. (Note: BC-only training gives u no
direct threat supervision; if u does not become threat-selective by itself,
that is a finding, not a license to cheat. Ablations measure this.)

**Anti-cheat declarations:** no pellet coordinates in any input; scenario
harness uses env internals ONLY to (a) build scenarios (remove/occlude
pellets, spawn ghosts) and (b) score ground truth — never to form a
observation. Evaluation episodes = TRAIN seeds `partition_seeds(f,"TRAIN")[:5]`
× F0..F4 (the same diagnostic episodes as the T1-4 probe, so prior
[MEASURED] numbers are directly comparable), plus the 5 scenario variants.

## 3. Scenario battery (built on the frozen harness env, deterministic)

- **S1 visible pellet:** standard episode; report acquisition (pellet
  fraction), time-to-first-pellet, trajectory efficiency (pellets / ticks
  spent not adjacent to pellets).
- **S2 pellet disappears:** after the agent's 20th pellet, ALL pellets on
  the board are removed (no respawn). Score: post-removal movement — does it
  keep moving toward unexplored/last-known region (measured: mean pellet
  removal rate before removal; post-removal fraction of ticks moving toward
  centroid of uneaten region) vs lockup (idle fraction).
- **S3 distraction:** while pursuing, force-spawn a direct-chase ghost
  adjacent-ish (via env restore + ghost injection through the public
  constructor kwargs: an episode variant with ghost_count+1 direct). Score:
  survival, pellet loss during threat window (±30t), **resumption** (pellet
  rate in the 100t after threat window vs the 100t before).
- **S4 self-induced distribution shift:** run Model on F0_calm for 1500t
  then teleport the agent (via snapshot restore into an uneaten corridor far
  from lockup state) — measures escape from the observed constant-W lockup.
  Score: action entropy over 200t post-teleport, recovery pellet rate.
- **S5 multiple pellets / target preference:** standard episode (board has
  many pellets); score = directional commitment (fraction of the time the
  agent's heading has a consistent pellet-region target over 60t windows) —
  proxy via entropy of 60t-window displacement directions.

## 4. State-utility tests (mandatory; Model C only)

1. **Temporal persistence:** autocorrelation of h over 60t within episodes.
2. **Task correlation:** linear probes from h → (a) pellet-present flag,
   (b) distance-to-nearest-pellet (binned), (c) ghost distance, (d) lockup
   state. Report R² per target; compare vs Model B's h (fairness).
3. **Interventions:** freeze h; zero h each tick (memoryless); random-walk
   noise into h; reset h at t=1500; disable shunting gate (g≡0); disable
   modulation (temp≡1); untrained u. Each re-run on the S1–S5 battery +
   families; behavior delta = causal contribution.
4. **Specialization:** no pre-assigned labels; cluster h dimensions/post-hoc
   correlate top-variance directions with task variables; lesion-by-zeroing
   each h-dim, report which lesion hurts which metric. Honest report if the
   32-dim state is redundant/distributed.

## 5. Latency / cost gates

Forward-pass latency measured on the same machine, 1000 warm single-tick
forwards, p50/p95/p99/max, compared to A. Budget: the harness TIMING_GATES
target median ≤ 8 ms L_plus — both must stay far under; any model with p99
> 1 ms (CPU single-thread forward) is flagged.

## 6. Frozen acceptance classes (decide BEFORE running; class the result,
never re-tune thresholds after)

- **KEEP** if C vs A on the family battery: pellet-fraction improvement
  ≥ +0.05 mean AND no family drops below A by more than 0.02 AND survival
  never-dying property preserved AND latency gate passes AND the persistence
  probes show h carries task-persistent information beyond B.
- **TEST FURTHER** if direction positive but any seed cohort member
  contradicts, or effect ≤ 0.05.
- **REJECT** if C ≤ A, or C ≈ B (structure no better than generic
  recurrence), or latency/param budget violated.
- **A is never retrained, re-tuned, or weakened; B is the honest
  parameter-matched control.**
